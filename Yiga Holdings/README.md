# Yiga Holdings Corporate Website

This repository contains the source code for the Yiga Holdings one-page corporate website. The website is built as a premium, sophisticated landing page to represent the holding company's strategic vision, diversified investments, and long-term expansion goals.

## Project Structure

```text
yiga-holdings/
│
├── index.html        # The complete one-page structure
│
├── css/
│   └── style.css     # Premium styling, variables, layout, and animations
│
├── js/
│   └── script.js     # Vanilla JS for smooth scroll, nav states, scroll reveals, and form validation
│
├── assets/
│   ├── images/       # Placeholder directory for imagery
│   ├── icons/        # Placeholder directory for icons
│   └── logo/         # Placeholder directory for logos
│
└── README.md
```

## Technologies Used

- **HTML5**: Semantic document structure.
- **CSS3**: Custom design system using variables, Flexbox, Grid, transitions, and animations.
- **Vanilla JavaScript**: Lightweight interactive features with zero external dependencies.

## Usage

Since this is a static website, no build step or package manager is required. Simply open `index.html` in any modern web browser or serve it using a local static file server:

```bash
# Example using Python 3
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Design Identity

The website features an original visual identity designed specifically for Yiga Holdings:
- **Colors**: Deep Charcoal base, Off-White neutrals, and a refined Gold accent color.
- **Typography**: Playfair Display for authoritative, editorial headings and Inter for highly legible body copy.
- **Interactions**: Smooth scrolling, glassy sticky headers, scroll-triggered reveals, and elegant hover states.
